# قیمت‌یار — بازار رقابتی خرید (نسخه نمایشی)

وب‌اپ فارسی راست‌به‌چپ برای **حراج معکوس**: خریدار درخواست کالا یا خدمات ثبت می‌کند و فروشنده‌ها برای تأمین آن پیشنهاد می‌دهند. خریدار قیمت و شرایط را مقایسه می‌کند.

## اجرا
`index.html` را در مرورگر باز کنید یا با `python3 -m http.server 8000` روی localhost اجرا کنید.

## امکانات
- فهرست و دسته‌بندی درخواست‌ها، جست‌وجو و مرتب‌سازی
- ثبت درخواست خرید و پیشنهاد قیمت **آزمایشی**
- مقایسه ۳۰ پیشنهاد ساختگی برای درخواست نمونه
- نمای خریدار و فروشنده، اعلان نمایشی و معرفی طرح VIP
- طراحی موبایل‌پسند و امکان ذخیره تغییرات دمو در localStorage مرورگر

## هشدار
این نسخه فقط فرانت‌اند است؛ حساب واقعی، پایگاه‌داده، پرداخت، احراز هویت و همگام‌سازی پیشنهادها بین کاربران ندارد. قیمت‌ها و فروشنده‌های اولیه ساختگی‌اند. برای استفاده تجاری باید API امن، دیتابیس، احراز هویت و سیستم اعلان پیاده‌سازی شود. داده‌های localStorage به‌عنوان اطلاعات معتبر تجاری قابل اتکا نیستند.

## GitHub Pages
سایت فقط در همین مخزن قرار دارد و به دیگر پروژه‌ها، سرور یا دامنه‌ها دست نمی‌زند. برای انتشار، در Settings → Pages گزینه **GitHub Actions** را انتخاب کنید. فایل workflow در `.github/workflows/pages.yml` آماده است. انتشار سایت از مخزن خصوصی ممکن است بسته به پلن و تنظیمات GitHub در دسترس نباشد.

> نمایش آزمایشی؛ حراج واقعی نیست.

## وضعیت انتشار
پس از فعال‌سازی GitHub Pages در Settings → Pages و انتخاب GitHub Actions، هر تغییر در شاخه `main` نسخه آزمایشی را به‌روزرسانی می‌کند. اگر اجرای قبلی قبل از فعال‌سازی Pages ناموفق بوده، این commit انتشار را دوباره آغاز می‌کند.
